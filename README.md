# Alam Store Annual Report 2022 – Excel Dashboard

## 📊 Project Overview

This project is an interactive Excel dashboard created to analyze Alam Store's 2022 sales and order data.

The dashboard provides insights into sales performance, customer demographics, order status, top-performing states, and sales channels using interactive slicers.

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Analysis

The dashboard analyzes:

- Total Sales and Orders
- Sales comparison between Men and Women
- Order Status distribution
- Top 5 States by Sales
- Age Group and Gender analysis
- Orders by Sales Channel
- Category-wise performance
- Monthly sales/order trends

## 🔍 Key Insights

- Women customers contributed a significant share of the overall sales.
- A few states generated a higher proportion of total sales compared with other states.
- Online sales channels contributed substantially to total orders.
- The dashboard shows differences in purchasing patterns across age groups and genders.
- Order status analysis helps identify the proportion of delivered, cancelled, returned, and other orders.
- Monthly analysis helps identify changes in sales and order volume throughout the year.

## 🎛️ Interactive Features

The dashboard includes interactive slicers for:

- Category
- Month
- Channel

These slicers allow users to dynamically filter the dashboard and explore different aspects of the sales data.
